# Company Tours Website

A simple, multi-page frontend website designed to showcase company tour packages, provide business details, and collect customer inquiries.

## 🚀 Features
* **Home Page:** Displays the company name, a brief overview of the tours, and quick contact details.
* **About Page:** Provides detailed background information about the company.
* **Customer Inquiry Page:** Features a functional HTML form designed to collect customer information and booking requests.
* **Multi-Page Layout:** Clean and simple navigation across three distinct pages.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 *(Update if you used any framework like Bootstrap)*
